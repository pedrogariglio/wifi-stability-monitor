# Codex Sessions

Este directorio contiene el registro de interacciones con Codex.

## Estructura

- raw/: sesiones crudas exportadas desde Codex
- processed/: sesiones resumidas y estructuradas
- insights.md: aprendizajes acumulados del proyecto

## Objetivo

Construir una base de conocimiento técnica reutilizable
y documentar decisiones tomadas durante el desarrollo.
