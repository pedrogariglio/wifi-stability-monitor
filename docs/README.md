# Documentacion del proyecto

Este directorio concentra la documentacion tecnica permanente de `wifi-stability-monitor`.

## Estructura

- `PROJECT_STATUS.md`: estado operativo actual del proyecto, riesgos y proximos pasos.
- `architecture.md`: arquitectura permanente del sistema.
- `deployment.md`: instalacion y despliegue desde cero.
- `runbook.md`: procedimientos operativos.
- `troubleshooting.md`: incidentes repetibles y su resolucion.
- `decisions/`: ADRs (Architecture Decision Records).
- `codex/`: historial tecnico de sesiones y manual tecnico acumulativo.

## Regla de mantenimiento

La documentacion se actualiza junto con el codigo. Cada cambio tecnico relevante debe reflejarse en el documento que corresponda.
